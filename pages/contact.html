Common Questions

Quick FAQ

Is this app really free?
Yes, 100% free forever. We rely on donations & affiliate sales to sustain it.
Can I use this offline?
Yes! It's a Progressive Web App (PWA). Add to home screen on mobile for offline access.
How accurate are prayer times?
We use the Muslim World League calculation method via Aladhan API — same as most Islamic apps.
Can I contribute translations?
Absolutely! Send us a message above or open a PR on GitHub.
